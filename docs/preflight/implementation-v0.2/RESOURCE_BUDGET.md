## Checkpoints and stop rules

- At20%: frozen baseline/schema/job slice and bounded M02P comparison/decision must be reviewable; otherwise reassess architecture before expanding features.
- At40%: end-to-end source→review→canonical surface→layered part must work in a test branch; blocked inputs enumerated.
- At60%: stop new optional features; demonstrate minimum vertical slice including selected-poser/reference-art migration pilot where inputs/engineering permit. Preserve40% closure reserve. If critical mechanics fail, use remediation and submit narrowed scope/budget decision rather than lower acceptance thresholds.
- At80%: require audited integrated candidate, migration/failure results and closed required license findings. Remaining work is remediation/docs/release proof; no technology shopping.
- At90%: freeze release scope; use last10% only to close tests/notices/clean-clone/docs or return a precise incomplete/blocked handoff. Full acceptance cannot be declared because time is exhausted.

Pause only the affected work on external inputs. On corruption/provenance breach, quarantine affected data, preserve logs and stop the affected pipeline until diagnosis. Stop all implementation when authorization is revoked or budget cap reached; return exact commit/worktree/tests/open findings without tagging a false release.

M02P uses up to 60000 tokens/7.2 agent-hours/96 tool calls for three bounded alternatives and one targeted correction each, not full editor rewrites. Independent review retains its own protected allocation. At an unresolved selection, halt target-dependent rig work and return evidence/gaps rather than consume closure reserves or default to historical topology. The total envelope and 40% closure reserve are unchanged.

## Context discipline

One stable contract brief≤8000 tokens per assignment. Keep normal active context≤60% of the model's available window; reserve≥40% for results, review and handoff. Checkpoint before pressure/compaction with exact paths, hashes, changed decisions, tests, blockers and next action. Read relevant source excerpts, never minified model/base64 payloads into context. Source manifests/records are on disk; screenshots only when needed for visual decisions. Do not repeat the broad Gate 2C survey.

Use immutable revision/commit references in all cross-agent packets. Director owns the architecture brief; Builder is sole schema/integration editor. At most one bounded provider/poser/face specialist works alongside Builder on disjoint modules. Role reviews use a fixed commit; changes invalidate affected reviews. Six independent roles run in waves under the four-active-agent cap.
