## Order and concurrency

Critical foundation: M00 → M01, then M02 jobs and M02P bounded poser comparison may proceed in parallel. M02 → M03 → M04 supports provider-neutral authoring; M02P choice is required before production-specific M05/M06 binding/rendering freeze. Generic surface/overlap/schema work can continue while selection is unresolved. After contract freeze, M07a can run alongside M06 in disjoint face files; M08 composition mechanics follow their schemas. M09 follows selected-poser primitives and actual surfaces, revalidating M02P with now-available reference art; it does not wait for second head/pair footage or mandate old topology. M10 mechanics and M11 records can use mocks; production anchor/substitution gates remain blocked until real inputs/tests. M13 integration begins incrementally after each merge and closes last.

The minimum first vertical slice is intake of one controlled clip + native frame inventory → manual/fast pose and component proposals → persistent person/component review → one source-preserving canonical surface → layered arm/shoulder part with distinct joint/pivot/socket → selected-poser pilot with reference-art migration → portable reopen. Do not begin parallel elaborate editors before this path works. Head/pair mechanics follow frozen core contracts.

Each exit packet includes exact commit/diff, changed schema/lock IDs, test commands and fresh results, visual evidence, remaining limitations, provenance/roundtrip checks, auditor findings and tester result. Mark BUILD_COMPLETE / VALIDATION_BLOCKED distinctly; neither means owner acceptance. Preserve historical Gate 2B/C findings and failed trials. Do not rewrite thresholds to fit a candidate.

## Pause and change control

Stop the affected milestone on an unresolved architecture conflict, required license gap, data corruption or invalid provenance; continue independent authorized work. Director records options/cost and obtains owner decision where authority/scope changes. Missing later inputs do not force unrelated foundational work to stop. Budget exhaustion triggers a bounded checkpoint and owner decision, not silent scope/quality reduction.
